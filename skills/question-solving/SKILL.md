# 题目解析生成

## 何时触发
- 教师端点击 ✨ 自动解析按钮
- 用户说："解一下"、"出步骤"、"详细解析"、"参考答案怎么写"

## 输出格式约定（严格）
```
【分析】
（一句话点明考点和思路）

【解答】
步骤 1：...
步骤 2：...
...

【答案】
最终结果用 $...$ 包起来
```

- 数学公式用 KaTeX 语法：`$x^2$`、`$$\int_0^1 x dx$$`
- 多个小问用 `(1) ... (2) ...` 分段
- 关键步骤后面注明 **依据**（哪条定理 / 公式）

## 调用接口
```
POST /api/academy/solve
{ "question": "<题干>", "answer": "<可选 已知答案，用来对齐>" }
```
返回 `{ solution: "..." }`，直接 PUT 到题目：
```
PUT /api/academy/exams/{exam_id}/questions/{q_id}
{ "solution": "<生成的内容>" }
```

## 质量检查清单
- [ ] 公式全部 KaTeX 包裹
- [ ] 步骤编号清晰
- [ ] 最终答案与已有 `answer` 字段一致（不一致时在【答案】下方加注 "⚠️ 与原答案不符，建议核对"）
- [ ] 不超过 800 字（超过则压缩冗余推导）

## 失败重试策略
- 第 1 次失败 → 把 `temperature` 降到 0.3 重试
- 第 2 次失败 → 把题干截短到 500 字再调
- 第 3 次失败 → 返回提示让用户手填
