# wisdomdrawingschool
This project is not yet deployed, as ongoing revisions and feature refinements are in progress. Only partial prototype deliverables are shared here.

It serves part-time tutoring educators and students, visualizing abstract spatial concepts such as solid geometry and functional graphs. Built with an interactive drawing canvas & auto question-generating module, it efficiently cuts teachers' lesson preparation overhead and provides targeted repetitive practice for learners.


This project remains undeployed due to pending function adjustments and optimization. Only semi-finished prototype content is presented.

Designed for part-time private tutors and students, it realizes visual presentation of abstract solid geometry & function spatial images. With an interactive sketchpad and automatic test paper generation, it lowers teachers' lesson preparation burden, and supplies matching exercises to help students master difficult abstract math knowledge.
