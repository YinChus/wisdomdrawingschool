🔗 LangGraph
用于五阶段试卷分析流水线：
parse → classify → solve → visualize → validate

入口：教师端「🤖 全自动分析」按钮 →
POST /api/academy/exams/{id}/run-agents
🔭 LangSmith
自动追踪所有 LangGraph/LangChain 调用。
无需改代码，只需在 .env.local 中设置：

LANGCHAIN_TRACING_V2=true LANGCHAIN_API_KEY=ls_... LANGCHAIN_PROJECT=exam-parse
🔧 MCP 工具注册表
内置 MCP 协议工具（academy_agents.py）：

calculate classify_math get_style generate_geogebra_prompt 在 classify / visualize 节点中被调用。
